Pocket Scanner: overview and repo consolidation

Started 2026-10-04 · Revision 2 (2026-10-04) · Status: done. Decisions settled, consolidation complete

Pocket Scanner is custom firmware for a Temporal Replay 26 conference badge, turning it into a handheld Bluetooth scanner. Today the work sits in two GitHub repos, and one of them (temporal-badge-scanner) only holds docs. This page describes the project and records the consolidation: the docs were folded into pjerus/Temporal-Replay-26-Badge and the docs-only repo was deleted.

1. What the project is

The badge is an ESP32-S3 handheld with a small OLED screen, an 8×8 LED matrix, a joystick, four buttons, a motion sensor, infrared send/receive, WiFi and Bluetooth LE. It has no speaker; the only “sound” is the vibration motor buzzing. Apps are small MicroPython programs stored on the badge’s file system; the core is C++ (Arduino framework, built with PlatformIO).
