Pocket Scanner: overview and repo consolidation

Started 2026-10-04 · Revision 1 (2026-10-04) · Status: proposal, nothing changed yet

Pocket Scanner is custom firmware for a Temporal Replay 26 conference badge, turning it into a handheld Bluetooth scanner. Today the work sits in two GitHub repos, and one of them (temporal-badge-scanner) only holds docs. This page describes the project, then proposes folding the docs into pjerus/Temporal-Replay-26-Badge and deleting the docs-only repo.

1. What the project is

The badge is an ESP32-S3 handheld with a small OLED screen, an 8×8 LED matrix, a joystick, four buttons, a motion sensor, infrared send/receive, WiFi and Bluetooth LE. It has no speaker; the only “sound” is the vibration motor buzzing. Apps are small MicroPython programs stored on the badge’s file system; the core is C++ (Arduino framework, built with PlatformIO).

Known loose ends

  • Five Bluetooth names were hand-patched into a generated file, with a workaround in qstr.c. The proper fix is re-running setup_arduino_embed.sh.
  • The factory-restore path in CLAUDE.md says ~/backups/...; the file is really at pi-arduino/backups/firmware-v0.2.4/.
  • The registry entry in ~/ai-dev/index.html says GitHub none and describes Phase 2 as covering BLE, WiFi and IR. Both are out of date.
